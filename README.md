## English

### Project Description

This project is a responsive online store frontend developed using React. It leverages Material UI for a polished design and Firebase for backend services. The application allows users to browse products, manage a cart, and potentially handle user authentication.

### Features

- **Fast & Responsive:** Built with Vite for comprehensive speed and optimized for all devices.
- **Modern UI:** Styled with Material UI (MUI) components for a professional look and feel.
- **Routing:** Client-side routing implemented with React Router DOM.
- **Image Management:** Image uploading capabilities using `react-images-uploading`.
- **Backend Integration:** Configured to work with Firebase.
- **HTTP Requests:** Uses Axios for API communication.

### Tech Stack

- **Core:** React 18, Vite
- **Styling:** Material UI (@mui/material, @emotion/react, @emotion/styled)
- **Routing:** React Router DOM
- **Utilities:** Axios, UUID, Firebase

### Installation and Setup

1.  **Clone the repository:**

    ```bash
    git clone https://github.com/Gmach07/Online-Store-React.git
    cd app_frontend
    ```

2.  **Install dependencies:**

    ```bash
    npm install
    ```

3.  **Run the development server:**

    ```bash
    npm run dev
    ```

4.  **Build for production:**
    ```bash
    npm run build
    ```

## Español

### Descripción del Proyecto

Este proyecto es el frontend de una tienda en línea moderna desarrollada con React. Utiliza Material UI para un diseño pulido y Firebase para servicios backend. La aplicación permite a los usuarios navegar por productos, gestionar un carrito y manejar la autenticación de usuarios.

### Características

- **Rápido y Responsivo:** Construido con Vite para una velocidad integral y optimizado para todos los dispositivos.
- **Interfaz Moderna:** Estilizado con componentes de Material UI (MUI) para una apariencia profesional.
- **Enrutamiento:** Enrutamiento del lado del cliente implementado con React Router DOM.
- **Gestión de Imágenes:** Capacidades de carga de imágenes usando `react-images-uploading`.
- **Integración Backend:** Configurado para trabajar con Firebase.
- **Peticiones HTTP:** Usa Axios para la comunicación con la API.

### Stack Tecnológico

- **Núcleo:** React 18, Vite
- **Estilos:** Material UI (@mui/material, @emotion/react, @emotion/styled)
